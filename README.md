# 🧮 Python Calculator & Interactive Dashboard

A Python-based calculator that supports complete mathematical expressions through a command-line interface and an interactive web dashboard built with Streamlit.

## ✨ Features

- ➕ Basic arithmetic: Addition, subtraction, multiplication, and division
- 🔢 Multiple-number expressions in a single calculation
- 🧠 Operator precedence and parentheses support
- ⚡ Exponentiation and modulus operations
- 📜 Calculation history with clear-history functionality
- 🛡️ Input validation and error handling
- 🌐 Interactive dashboard built with Streamlit
- 🔍 Safe expression parsing using Python's AST module

## 🛠️ Tech Stack

- **Language:** Python
- **Web Dashboard:** Streamlit
- **Expression Parsing:** Python AST
- **Libraries:** `ast`, `operator`, `math`, `streamlit`
